# Бейджанс

Сайт кофейни «Бейджанс» на Ленинградском проспекте, 13, стр. 1 (Москва, метро «Белорусская»).

Статический сайт без сборки: `index.html`, `styles.css` (`tokens.css` и `base.css` подключаются из него), `app.js`.

- Данные о меню, часах и отзывах взяты с Яндекс Карт (меню обновлено 20 сентября).
- Фото сейчас временные (Wikimedia Commons, авторы указаны в футере). Промпты для своих кадров в `PROMPTS.md`.
- Шрифты Oswald и Golos Text лежат локально в `fonts/`.

Локальный просмотр:

```bash
python3 -m http.server 4321
```
